# Agent Builder copy kit

Copy the complete contents of [name.txt](name.txt), [description.txt](description.txt) and [instructions.txt](instructions.txt) into the corresponding Agent Builder fields. Use [starter-prompts.json](starter-prompts.json) for the suggested prompts.

The owner's exact configuration uses the agreed generic data-source wording. Branding is applied to the surrounding guide and optional [JH agent icon](../assets/branding/jh-agent-icon.png), without adding text to the configuration fields.

# Synthetic practice sources

Every number, organisation, statement and action in these files is fictional. They are not a Cornwall & Isles of Scilly operational position or an actual operational data schema. No patient records are included.

Create a separate test agent and test SharePoint location. Place the two snapshot `.txt` files in its test equivalent of the **Daily Operational Snapshot library**, and the meeting notes in its narrative knowledge. Do not add this README, the acceptance criteria or golden answers as knowledge. Never include these files in the production agent.

The sample chronology is **12 September 2026 at 08:30 Europe/London (UTC+01:00)**. For a fresh-source test on a later day, make controlled local copies and shift every date consistently while retaining the intervals and comparison values. Record the change in your private test log. Do not simply tell the agent that an old real-time snapshot is fresh. Keep the original dates for a stale-source case.

Use `tests/ACCEPTANCE_TESTS.md` as a reviewer-only answer key. All model tests start **Not run** and must be performed in your tenant.

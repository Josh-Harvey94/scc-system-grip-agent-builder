# Historical source materials — superseded configuration

These are the owner's earlier SCC System Grip Agent Builder Guide materials. They are retained as historical references with source-specific naming generalised at the owner’s request. The PDF has a reference footer, the owner’s JH signature and a subtle corner watermark. Both HTML editions carry the same creator branding and work locally. These copies are not byte-identical to the supplied files.

- `REFERENCE_SCC_System_Grip_Agent_Build_and_Operating_Guide.pdf`: 22-page handbook dated 11 September 2026.
- `REFERENCE_SCC_System_Grip_Agent_Build_Companion.html`: earlier interactive companion with generic source naming.

**Do not copy their agent description or 5,478-character instruction set into a new build.** The owner subsequently supplied the actual exact configuration, including the full morning start-of-play layout. Use [../agent/instructions.txt](../agent/instructions.txt), [../agent/description.txt](../agent/description.txt) and the [updated companion](../SCC_System_Grip_Agent_Build_Companion.html).

Download and extract the repository, then open [SCC_System_Grip_Agent_Build_Companion.html](../SCC_System_Grip_Agent_Build_Companion.html) from its root folder. The PDF cover points to this included file; no hosted companion is needed. Both HTML files embed their scripts, styles and branding. Microsoft documentation links remain optional reference material.

# Working templates

Use these structures for local source documentation, briefing, handover and release records. Replace bracketed guidance with reviewed local information. They are templates, not operational evidence.

Each file carries a short template-design credit. For a formatted Word, PDF or HTML output, use the [JH branding assets](../assets/branding/README.md) as a small footer signature and corner watermark. Keep the required source note intact and distinguish local authorship of the operational content from authorship of the template.
